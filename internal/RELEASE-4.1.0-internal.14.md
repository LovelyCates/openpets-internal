# 4.1.0-internal.14：待机恢复、控制中心整理与跨平台核对

本轮以用户实际使用的 macOS Internal 12 / Electron 42 为行为基线，对照已交付的
Windows Internal 13 / Electron 45.3.3。未替换正在运行的 Mac 应用，也未复制、
重置或提交其私有配置和宠物库。

## 实际包核对

从 Mac 12 的实际 ASAR 读取动画 owner，与 Windows 13 实际安装包生成的文件
清单逐项对照。以下行为已随 Windows 13 交付，并非仅存在于 Mac 工作目录：

- V1 六列待机的非均匀停留，总周期 6600ms。
- 15–30 秒安静时机触发短暂挥手或跳跃，悬停动作及普通点击保留规则。
- 忙碌动画三轮后回慢待机；会话状态、tk/s、AVG 继续实时更新。
- CSS 动画就绪后才开始三轮预算，以及系统减少动态效果偏好。

对应样式、活动调度、body 状态、窗口移动和动画定义共九个文件字节一致。
preload 输出有构建器格式变化；main 的主要差别是 Internal 13 的安全存储修复。
Electron/Chromium 版本和原生窗口系统仍有真实差别，代码一致不能证明流畅度一致。
新装 Windows 默认内置 V2，实际 Mac 选择的是导入的 Yukino V1；二者素材和
V1 专用空闲手势能力也不同。

## 共享修复

原窗口移动发布器在任意坐标变化时取消空闲动作，但切换移动姿态要求累计
3px。现在二者共用实际移动阈值，避免亚阈值原生坐标噪声反复重置空闲预算；
慢速连续移动仍累计，180ms 静止后的重新锚定规则保留。

拖拽恢复统一释放窗口 movement blocker、活动、注视与速度记录，并同步取消
当前 renderer 的同一次拖拽反馈。显示器/电源恢复、导航、加载失败、隐藏及关闭
均清理中断状态；旧取消或延迟松手不能影响新拖拽，也不能产生过期抛出动作。
这些修复位于 Win/Mac 共享 owner，不引入平台动画分叉。

启动日志补充应用/Electron/Chromium 版本、图形能力、有效系统动画偏好和素材
版本，用于区分运行条件。未关闭系统减少动态效果，也未更改置顶、GPU 或后台
节流策略。已复现的代码缺陷不等于已证实用户机器的唯一成因。

## 验证边界

Windows 发布流水线新增最终 NSIS 内实际 GUI 的 V1/V2 播放检查，使用独占新建的
GitHub hosted-runner 配置。真实 IPC 导入、自然空闲手势、CSS 时钟、可见像素及
公开原版 Yukino 的固定 SHA 场景均留有单独证据。便携测试或 Mac 侧 Electron
实验不能代替该 Windows 检查；rAF 采样也不代表用户 GPU/DWM 的实际呈现帧率。

最终构建、原生运行结果和安装包校验值随对应 GitHub Release 提供。

## 控制中心与速度栏

助手移除“服务提供方”栏目和旧直达入口，保留聊天与语音、人设个性及对话
归档。设置隐藏远程控制、局域网及对应弹窗，不再为隐藏栏目主动读取状态。
这些是共享 Control Center 的界面调整；已有私有配置保持。

旧版尚未提供独立 tk/s 显示入口。本版在“设置 → 常规 → 宠物行为”中，
插件 HUD 大小下方增加“Token 速度（tk/s / AVG）”。默认开启，保存后立即
生效；关闭后不占用速度栏空间，继续接收本地会话与采样，重新开启即显示
最新实时速度和平均值。实际 production preload 验证了隐藏期间的新数据、
无需新消息的恢复，以及宠物节点、CSSAnimation 对象和时钟的连续保留。

内部版关闭 Teams 时，宠物签到读取返回契约允许的空快照，避免正常启动时
请求未初始化服务而报错。服务后续就绪仍走原订阅更新；提交保持严格检查。

## 内置插件点击路径

逐项验证 11 个内置插件的配置、启停与命令路径，覆盖真实 Control Center
renderer/preload、IPC、Service、Runtime 与 SDK bridge，外部通知等效果使用
隔离 host 记录。自定义声音选择取消后不再解引用不存在的声音；插件命令
失败会反馈给界面，表单失败保留当前输入；已停止或重载的旧 renderer 不再
收到失效的回调，异步回调拒绝由既有诊断通道处理。

Windows 原生回归另发现旧开发插件记录清理使用固定 `/`，无法识别 Windows
路径。两处分支统一使用平台路径边界判断，保留真实路径检查，并明确拒绝
同根、相邻前缀、父级、异盘及 junction 逃逸；缺失目录也使用相同边界规则。

Windows 首次画面验收曾被启动问候的合法动作切换触发首尾时钟误判，原报告
保留。验收改为连续记录语义、document/sprite/动画身份及自然时钟，并要求
稳定待机窗口和实际帧像素变化。Windows 系统的减少动态效果原值和测试覆盖
媒体值单独记录；覆盖后通过不等于系统默认动画已验证。
