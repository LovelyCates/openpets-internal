## 图库与收藏

控制中心突出全库搜索，支持 Unicode 规范化、多关键词，以及名称、ID、描述、
原站标签和发布者检索。来源、V1/V2/Motion、装扮及活动筛选带实际计数，
类型、标签和发布者可组合；过滤后再分页，每页最多挂载 24 张卡。
没有来源分类信息的旧条目明确为未分类，不按名字猜题材。

卡片和详情的星标写入独立 `favoritePetIds` 偏好，经既有授权 IPC 持久化。
收藏与默认宠物、桌面固定和会话池分别维护。初次读取有加载及错误重试状态，
避免尚未收到数据就显示零宠物。移除结果顶部的 Studio 大横幅，压缩筛选区，
少量结果的卡片也按自然高度排列。

收藏等仅偏好变化复用现有的私有安装记录缓存，不重扫未变 manifest；启动及
新增/替换记录仍验证磁盘资源。额外 11 项状态/渲染偏好回归通过，旧 owner
会在新增用例中产生 4 次额外读取，修改后为 0。

## 两种 ZIP 共用安装与播放器

本地导入明确提供 OpenPets / OpenCode Pet ZIP、Codex Pets ZIP、文件夹及取消。
选择 Codex 来源后记录 `source.kind=codex`；来源标签不用于判断图片格式或
绕过验证。平铺和受支持的单层 wrapper ZIP 走同一受限解包、格式校验、私有
候选及原子安装事务，失败保留原安装，不主动切换默认宠物。

本地客户端的 `installLocalPet(path, { kind, origin: "codex", libraryMetadata })`
也支持 ZIP/文件夹。可选 `libraryMetadata` 在 `pet-format` 由唯一严格 schema
验证，服务端在文件访问前校验，随原安装事务写入状态；不塞进原宠物 manifest。
客户端保留可独立发布的 wire type，不增加对私有包的 runtime 依赖。

原站 ZIP 不一定包含标签和上传者；全量导入使用目录 sidecar 保留这些信息。
手工导入没有这些字段时不会捏造分类。两种来源的同格式宠物使用相同 body
协调器、帧时序、交互、状态和 token 显示路径，不按来源另设动画实现。

## 三轮忙碌动作与实时状态

Classic V1/V2 的循环忙碌行播三轮后，仅在 renderer 局部呈现慢待机。
真实会话 context、忙碌标识、气泡、tk/s 和 AVG 继续更新。有效行相同的状态
细分、重复心跳、内容和 HUD 更新保留当前预算或休息结果；换行或时长才新开
三轮。中途修改动作映射/等待速度会立即更新投影，无需等下一次会话心跳。

预算等待实际 CSSAnimation ready 后启动，避免首次样式绘制较慢时提前计时。
复用现有单个预算 timer，Web Animations ready Promise 仅请求当前协调器
重新判断；旧 epoch、暂停、挂起、插件、活动及拖动沿原优先级和清理处理。
有限动作保留原有次数和新事件重播，Motion clips 保留独立播放合同。
V1 的 6600ms 待机不再乘倍率，V2 与内置猫保留各自既有待机停留。

## V1 点击反馈

跨 Chotu、Spyro、Mariglow 等素材核对发现，共用输入路径在按下时会中断
正在播放的 hover 手势；随后若发生拖动，窗口移动会切入跑姿，短时间内的
多次换姿放大原画差异。新版普通左键身体按下保留既有 hover 手势；实际移动、右键、离开或
新忙碌状态仍接管。pointer drag override 使用 >4px，独立 native-window
movement publisher 保留累计 3px，不能声称所有运动反馈统一为一个阈值。

所有状态使用同一源格和缩放，不按人物可见边界重新 fit。素材本身的朝向、
服装、道具和坐姿差异仍来自原画。原格比较保存在
`.local/cadence-20261117/assets/`，没有重绘或美化素材。
