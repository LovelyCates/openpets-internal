# packages/opencode/src/

## Files

- **index.ts**: Barrel export. Re-exports all public modules including path-safety helpers.
- **plugin.ts**: OpenCode 2.0 V2 `Plugin.define({ id, setup })` entry point. Owns event subscription, prompt/tool hook registration, option validation, and teardown (abort, dispose, drain, lease release).
- **opencode-plugin-runtime.ts**: `createOpenPetsOpenCodeRuntime()`, V2 event classification, tool reaction mapping, serialized lease acquisition, session/call-aware latest-state dispatch, a bounded failed-turn outcome latch, permission-reply restoration of ongoing work, independent speech cooldowns, 10s continuous-state refresh, a 5s quiet-tool keepalive, token-rate IPC dispatch, and unload cleanup. A guarded permission reply retains an activity-owned replacement intent across coalescing/acquisition until a neutral thinking-pool say succeeds; captured-object checks protect newer waits from older acknowledgements. New waits, activity switches, terminal state and cleanup cancel it. This replacement alone bypasses ambient speech cooldown. Failure clears queued/in-flight badge readings and rejects late usage until an explicit new turn.
- **opencode-token-rate.ts**: Pure V1/V2 usage-event parser, bounded rolling token/s estimator and cumulative observed-segment AVG (at least one second, character/4 total divided by first-to-latest delta elapsed time). Reports freeze AVG without counting report latency; new segment/session/clear resets it. Includes identified unfinished-part growth from full-text V1 snapshots and shared stream-activity recognition. Sends only validated session IDs and derived numbers; never forwards stream text.
- **opencode-plugin-v1-runtime.ts**: Maps V1 hooks and paired callID before/after completion to the session-aware runtime, normalizes 1.2.27 `permission.asked` bus requests plus the legacy ask hook without paths/arguments, filters the pet's own MCP permissions, and forwards V1 part/message usage events to the token-rate tracker.
- **opencode-config.ts**: Config file management. Path resolution, JSONC parsing, safe file operations, atomic writes with backups, actionable symlink/parent diagnostics.
- **opencode-path-safety.ts**: Shared safety message builders. Symlink target display, scope-aware (`global`/`project`) config/instruction/parent/directory error formatters, lstat-based existence helpers, and full-ancestor symlink rejection for global roots.
- **opencode-project-setup.ts**: Project-level setup. `prepareOpenCodeProjectSetup()`, `writePreparedOpenCodeProjectSetup()`, instruction block management with path-aware safety errors.
- **opencode-global-setup.ts**: Global setup management. `prepareOpenCodeGlobalSetup()`, `prepareOpenCodeGlobalRemove()`, cleanup writes, doctor command, config precedence handling, global state classification with actionable safety errors.
- **opencode-status.ts**: Status classification (147 lines). `classifyOpenCodeMcpStatus()`, `classifyOpenCodeInstructionsStatus()`, `classifyOpenCodePluginStatus()`, managed MCP/plugin/instruction detection helpers, OpenPets-like entry detection.
- **opencode-previews.ts**: Config entry builders (55 lines). `buildOpenCodeMcpEntry()`, `buildOpenCodePluginPreview()`, `buildOpenCodeInstructionPath()`, `formatOpenCodeMcpConfig()`, `validateOpenPetsPetArg()`.
- **check-opencode-foundation.ts**: Contract validation (excluded from detailed documentation).
- **check-opencode-plugin.ts**: Plugin contract validation, including wire requests through a private temporary discovery file (0600) and runtime directory, so real-client tests retain the production discovery security boundary.

- **check-opencode-realtime.ts**: Behavioral regressions for immediate transitions, delayed IPC coalescing, failed-send retry, session isolation, bounded terminal outcomes, V1 error/idle/completion bursts, late and in-flight badge clears, same-session turn recovery, permission-reply restoration and obsolete-speech replacement even during ambient cooldown, parallel completion/error, V1 streams, and fake-clock quiet-task refresh/lease cleanup.
